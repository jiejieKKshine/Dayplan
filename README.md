# Dayplan · 日序

一个中文日程管理网页，用月历整理课程、考试、汇报和生活安排。

## 功能

- 月历概览、当天详情、全部日程与搜索、分类筛选。
- 新建、编辑、删除日程，标记完成。
- 粘贴文字导入：支持 Markdown 表格、Excel 复制的制表符表格、CSV 和常见中文时间表达。
- 导入前预览、修改、勾选确认；保留起止时间与地点。
- 手动保存、载入、删除导入草稿；每次重新打开导入框都为空。
- 网页内提醒与浏览器系统通知。

## 技术栈

原生 HTML、CSS、JavaScript，无框架、无构建依赖、无独立后端。

日程和草稿保存在当前浏览器的 `localStorage`。解析在本地通过规则完成，没有调用大模型或外部 API。

## 本地运行

安装 Python 3 后，在项目目录执行：

```sh
python -m http.server 4173 --directory dist
```

打开 <http://localhost:4173>。也可以使用任意静态服务器托管 `dist/`。

## 验证

安装 Node.js 后运行：

```sh
node check-formats.cjs
node check-enhancements.cjs
```

检查覆盖多种表格格式、时间区间、日期标题、草稿保存和清空、日程删除取消及存储失败回滚。

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `dist/index.html` | 页面结构与响应式样式 |
| `dist/app.js` | 日历、日程管理、存储与提醒 |
| `dist/parser.js` | 基础中文日程规则解析 |
| `dist/parser-formats.js` | 表格、CSV、时间区间等格式解析 |
| `dist/import.js` | 解析预览、确认和批量导入 |
| `dist/enhancements.js` | 草稿管理、导入清空与直接删除入口 |
| `.openai/hosting.json` | 原 Sites 部署配置，本地运行无需使用 |

## 使用限制

- 数据不在设备之间同步；清除浏览器站点数据会删除日程和草稿。
- 提醒依赖网页保持打开，后台节流或设备休眠可能延迟提醒；不支持关闭网页后的服务端推送。
- 浏览器通知需要授权，通常要求 HTTPS 或 localhost。
- 规则解析不保证理解所有自然语言。导入前请核对；缺少日期和时间时需要补充。
- 每日安排按确认的连续天数生成独立日程；“每周”文本目前仅导入所列日期。

## 部署

将 `dist/` 部署到静态网站托管平台即可。当前版本无需 API 密钥、数据库或环境变量。
